# Tiffany Lau Portfolio Website

This folder is ready to upload to the `tlau85.github.io` GitHub repository.

## Files

- `index.html` — the page content
- `styles.css` — the design and layout
- `script.js` — automatically updates the footer year
- `assets/Tiffany-Lau-Resume.pdf` — résumé linked from the website
- `assets/images/` — sample project images to replace with your own

## Upload to GitHub

1. Open the `tlau85.github.io` repository.
2. Click **Add file → Upload files**.
3. Upload the CONTENTS of this folder, not the outer folder itself.
4. Commit the changes.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
7. Save.

The website should publish at:

https://tlau85.github.io

## Replace a sample image

Keep the same filename and overwrite the sample file, or change the image path in `index.html`.

For example:

```html
<img src="assets/images/properish-paper.jpg" alt="Properish Paper cards and packaging">
```

Use clear JPG, PNG, WebP, or SVG images. Landscape images around 1600 × 1200 pixels work well.
